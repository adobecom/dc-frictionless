AS-IS · CONSTRAINT

⑦ Why the verb page is authored twice — the prerender EdgeWorker loop

Root cause is the prerender EdgeWorker, not the URL path. Moving pages under /acrobat/online/ would NOT remove the duplicate — only a header flag does.

⚙️ A prerender EdgeWorker renders the LCP (verb-widget block)
Code lives in main.js in the da-dc repo (edgeworkers/Acrobat_DC_web_prod/main.js) · runs on both domains (www.adobe.com + acrobat.adobe.com).
➜
🔁 The problem — an endless fetch loop

To prerender the page, the EdgeWorker must fetch the page itself. But that fetch hits the same path the EdgeWorker runs on → the EdgeWorker fires again → infinite loop. It needs a way to tell "this request is me fetching, don't run again."

User request ➜ EdgeWorker
➜
EdgeWorker fetches the page…
➜
…which triggers the EdgeWorker again 🔁
➜
Fix 1 — Header flag ✅ used on www.adobe.com
Self-fetch carries a flag
X-EW-Frictionless-Page: true
EdgeWorker sees the flag → skips running on that fetch. One authored page.
ResultSingle source page · no duplicate · path-agnostic
Ref: da-dc / edgeworkers/Acrobat_DC_web_prod/main.js (the header is set there)
Fix 2 — Separate path ⚠ used on acrobat.adobe.com
Self-fetch routed to a different path
Route the EdgeWorker's fetch to /dc-shared/ so it does NOT hit the EdgeWorker path.
Requires the same content to also live under /dc-shared/ → a second authored copy.
ResultTwo authored copies to keep in sync, per verb · multiplied across every verb migrated
Ref: frictionlessResponseProvider() — da-dc / edgeworkers/Acrobat_DC_web_prod/main.js (~L254) has no flag, so it fetches the duplicated /dc-shared/ path
Why this one? The Acrobat team had concerns about adding another header flag (they already have many flags), so acrobat.adobe.com uses the duplicate-path workaround.
📌 Key point: the duplicate copy is independent of the URL path (root vs /acrobat/online/). It is removed only by adopting the header-flag approach — a decision that sits with the Acrobat team, separate from the repo (Decision A) and path (Decision B) choices.
